Stellar Idle - art slots
========================

Drop PNG files here with these exact names. They replace the generated placeholders
automatically (no code change, no scene setup). Texture Type can be "Sprite (2D and UI)"
or "Default". Use transparent backgrounds for everything except the background.

  background.png               Full-screen background, portrait (1080x1920 or larger)
  planet.png                   The tappable planet, square (512x512+)
  cargo_pod.png                Bonus drop pod, square (256x256)
  Icons/crystal.png            Premium currency icon (128x128)
  Icons/dark_matter.png        Dark Matter icon, used in the Warp tab (128x128)
  Generators/drone.png         One icon per generator id (see GameBalance.json), square 256x256:
  Generators/harvester.png       drone, harvester, lunar, station, mars,
  Generators/lunar.png           refinery, dyson, wormhole, forge, core
  ...

Free, commercial-use (CC0) sources to start with:
  - Kenney "Planets", "Space Shooter Redux", "Space Kit": https://kenney.nl/assets
  - OpenGameArt (filter by CC0 license): https://opengameart.org
Keep a single art style across all icons.
